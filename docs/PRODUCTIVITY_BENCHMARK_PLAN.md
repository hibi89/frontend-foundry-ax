# FFAX 검증 계획 — 실용성과 사용자 개입 감소 측정

2026-11-12 KST. **계획 문서: 현재 측정 결과 없음.**

## 비교 기준
- 비교군: 현재 ChatGPT+일반 프론트엔드 수작업 방식, FFAX 기반 생성/편집 방식.
- 대상: (1) 새로운 관리자 대시보드 (2) 기존 앱 UI 리디자인 (3) 레퍼런스 기반 스타일 생성.
- 실행 조건: 동일한 요구사항, 같은 환경·검수 규칙, 주요 화면·클릭 동선 동일, 최소 3회 반복.
- 별도 기록: AI 프롬프트 횟수, 사람이 준 수정 지시 횟수, 총 작업시간, 결함/재시도, API 비용, 최종 만족도.
- FFAX 0% 단계에는 실제 비교 결과 없음. 각 결과에 기초 소스 SHA, 대상 프롬프트, 브라우저/장비, CI 로그/스크린샷 링크를 붙인다.

## 성과 가설
- 디자인 재사용으로 화면 구성 지시 감소 가능.
- 마우스 편집으로 세부 UI 수정 반복 감소 가능.
- 자동 QA로 모바일·기능 회귀를 이전보다 빠르게 포착할 가능성.
- 단, 신규 구조·복잡한 리디자인·대규모 JSX·AI 모델 비용 등은 역효과가 있을 수 있으므로 측정한다.
