# IMAGE_ASSETS.md — 콘셉트 이미지와 UI 구현의 관계

- 사용자가 승인한 **FRONTEND FOUNDRY AX (FFAX) 최종 완성 개념도**는 2026-11-12 대화에서 생성된 1672×941 PNG(콘셉트 원본)이다.
- 사용자 승인된 원본 PNG의 WebP 변환본을 `assets/concepts/ffax-v1-vision.webp`에 보관한다. Blob SHA `01d42b4e74eed25a3b23ec6966f77b6bd7b22e54` 실제 검증. 원본 PNG 1:1 바이트 동일이 아닌 **시각적 압축 변환본**이다.
- 원본이 없으면 임의로 닮은 사진·웹 검색 결과를 원본으로 둔갑시키지 않는다.
- 이미지에 표현된 KPI, 프로젝트 화면, 버튼, 색, 일부 텍스트는 **제품 목표/가상 시연 값**이지 개발 사실·확인된 상업 성과가 아니다.
- 디자인 목표는 **다크 테마, 보라·파랑 포인트, 명확한 정보 계층, 좌측 작업공간, 중앙 프리뷰, 우측 컴포넌트/속성, 위쪽 프로세스, 아래쪽 사례 포트폴리오**. 세부 텍스트와 화면은 실제 앱 구현 때 정리·수정 가능.
- **디자인 반영 성공 판정:** (1) 사용자 승인 시안 (2) 반응형 375/768/1440 (3) 컴포넌트 재사용 (4) 실제 사용자 플로 (5) 접근성·콘솔 오류 없음 (6) 승인 전 원본 보존.
- 인쇄물/평면 이미지에서 디자인 토큰과 레이어를 100% 복원한다고 가정하지 않는다. 이미지 편집 가능한 소스 파일이 별도로 존재하는지 확인할 것.

**GitHub 변환 이미지:** 업로드 blob SHA 확인 후 feature tree에 포함됨. README 상대 경로에 표시. 원본 PNG 자체는 GitHub에 포함되지 않았고 별도로 보존.
