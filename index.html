아이디어를 디자인으로

기존 서비스의 결제·인증·API는 자동 수정하지 않습니다.

구조화된 요구사항

요구사항을 입력하고 분석하세요.

Design Forge · 디자인 생성 → 개선 → 레퍼런스 확정

무료 오프라인 FFAX 17종 컴포넌트로 A/B/C 소스 시안을 생성합니다. 디자인이 확정되면 React 코드·디자인 토큰·구조를 SHA256으로 잠가 기존 편집기로 전달합니다. 외부 이미지 생성이나 유료 API는 호출하지 않습니다.

선택 사항: 이 PC의 Qwen 4B로 다른 UI 구조 초안을 제안받을 수 있습니다. 이미지 생성 AI가 아니며 사용자가 결과를 검토해야 합니다.

컴포넌트 직접 편집 (선택 시안의 복사본만 변경)

확정 시안 · 실제 Playwright 화면 촬영 (선택)

Design Forge 준비 중.

이 단계는 실제 HTML 미리보기이며 Playwright PNG 촬영/정밀 시각 비교·실기능 수락은 별도입니다. 외부 이미지 레퍼런스는 기존 이미지 분석 경로에서 다룹니다.

기존 React 프로젝트 · 로컬 폴더 읽기 전용

명시적으로 선택한 React+TypeScript 폴더의 안전한 파일만 브라우저에서 해시·구조 분석합니다. 원본 수정·외부 전송·GitHub 인증·자동 적용 없음. node_modules 없이 정리된 폴더를 권장합니다.

선택한 폴더의 코드 내용은 서버로 업로드하지 않습니다. 검사 후 원본 SHA가 아닌 로컬 선택 파일 해시를 제공합니다.

GitHub 공개 저장소 · 커밋 고정 읽기 전용

공개 저장소만 지원합니다. GitHub API로 공개 코드 최대 16개를 표본 검사하며, 인증 토큰·원본 수정·PR·배포는 수행하지 않습니다. 사설 저장소와 실고객 API·인증 보존 검증은 미지원입니다.

같은 공개 저장소를 두 번 조회하면 별도 동의 후 비교할 수 있습니다. GitHub가 제공하는 파일 목록/라인 수 메타데이터만 조회하며 소스 패치·승인·PR은 제외합니다.
동의 전 외부 요청 0건. 비공개 저장소·쓰기·PR·토큰 입력 미지원.

무료 로컬 AI 생성 · Ollama 설치 PC

오직 이 PC의 127.0.0.1 모델에만 입력합니다. 유료 API·외부 업로드·자동 코드 적용 없음. 아래 별도 검토와 승인이 필요합니다.

Ollama가 실행 중이지 않으면 호출하지 못합니다.

AI 디자인 요청 · 수동 복사 방식

이 앱은 외부 모델에 연결하지 않습니다. 사용자가 직접 민감정보를 확인하고 요청서를 복사할 수 있습니다.

AI API 미연동 · 수동 요청/검토용 기능

참고 이미지 (선택)

이미지는 브라우저 안에서만 분석합니다.

V3 · 경계 기반 영역 위치와 의미 직접 정정

이미지를 선택하면 계층화된 영역 후보를 표시합니다. 폰트·OCR·React 구현은 별도 단계입니다.

V3 · 글자 영역 직접 기록 (OCR 미탑재)

위 영역 선택에서 텍스트가 속한 구역을 고르고, 실제 이미지의 텍스트와 x,y,width,height 좌표를 입력합니다. 자동 OCR이나 폰트 식별을 실행했다고 주장하지 않습니다.

한글·영문·숫자 수동 교정. 폰트·OCR confidence UNKNOWN.

V3 · 로컬 이미지/폰트 원본 SHA 목록

원본 자산 파일은 자동으로 저장/업로드되지 않습니다. SHA 기록은 렌더링 가능한 원본 제공을 의미하지 않습니다.

V3 · 이미지 구역 → 실제 React/TSX + CSS

원본 이미지 관측 영역과 직접 보정한 텍스트를 같은 계층 구조로 생성합니다. 필수 원본 자산을 등록했지만 실제 파일 바이트를 아직 연결하지 못한 경우 안전하게 차단합니다.

본 단계는 실제 CSS·DOM 코드 생성. 시각 95점·폰트·반응형·API 검증 전입니다.

위 별도 원본 Vault에서 이미지 SHA·권리·DPR 영수증을 먼저 생성해야 합니다. DPR 1 지원.

V3 · 원본↔실 Chromium 영역별 차이 분석

이미지 파일 SHA와 실제 캡처 SHA를 다시 확인합니다. 색상/경계는 대략 점수로 볼 수 있지만 글꼴/자산 및 95점 최종 점수는 현재 미검증으로 처리합니다.

실화면 캡처 전 F95=UNASSESSED. 판정 값을 억지로 만들지 않습니다.

외부 이미지에서 실제 UI 코드로 (사용자 영역 지정)

자동 분석으로 알 수 없는 텍스트·컴포넌트는 직접 입력합니다. 한 줄에 타입|텍스트를 쓰면 위·중간·아래 영역 순서대로 FFAX React 컴포넌트를 생성합니다. 복원 불가능한 원본 일러스트·폰트·숨겨진 동작은 별도 검토가 필요합니다.

이미지 분석 및 사용자 영역 지정 후 실행할 수 있습니다.

경계 기반 영역 분석은 대략적인 위치·색만 관측하며 폰트·텍스트·숨겨진 자산·95점 일치는 보장하지 않습니다.

검증 및 코드 내보내기

검증 전. 실제 브라우저의 스크린샷·콘솔·네트워크 검증은 별도 QA 스크립트를 실행하세요.

레퍼런스 ↔ 실제 화면 · 로컬 PNG 비교

레퍼런스 원본 PNG와 Playwright 등의 실제 캡처 PNG를 선택하세요. 같은 픽셀 크기만 비교하며 폰트·기능·원본 권한은 따로 검토합니다. 파일은 서버로 업로드하지 않습니다.

V3 · 참조 원본/화면 크기 영수증

바로 위 로컬 보관이 먼저 필요합니다. 사진의 실제 픽셀 크기로 캡처 화면을 고정하고, 소유자가 주장하는 권리만 기록합니다. 재배포 승인이나 상업적 이용 허가는 생성되지 않습니다.

보관된 원본 SHA를 이용합니다. 외부 서버에 전송하지 않습니다.

자동 저장/외부 업로드 없음. 이미지 자체는 공개 GitHub에 올라가지 않습니다.

비교 전

실측 기반 안전 자동 보정 · 후보만 수정

위 PNG를 기준으로 FFAX가 최대 1~5번 실제 Chromium 재촬영·픽셀 측정·타입이 고정된 수정안을 시도합니다. 더 나쁜 후보는 버리고 가장 좋은 화면만 제안합니다. 원본·기존 저장소·Production은 수정하지 않습니다.

확정 시안과 PNG를 선택해야 실행할 수 있습니다.

가져오기는 현재 편집 화면만 교체하며 원본 파일·GitHub는 수정하지 않습니다. 기존 화면은 Undo로 복구할 수 있습니다.

이 기기에서 작업 저장 · 재개 (수동)

현재 편집 프로젝트만 이 브라우저 저장소에 암호화 없이 기록합니다. 공용 PC와 고객 기밀이 포함된 프로젝트에서는 사용하지 마세요. 자동 저장·클라우드 동기화·GitHub 쓰기 없음. 브라우저 데이터 삭제 시 복구할 수 없습니다.

저장·복원·삭제는 각 버튼과 확인 절차를 거친 경우에만 실행됩니다.
